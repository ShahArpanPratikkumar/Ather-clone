Ather Website Clone is a front-end project created using HTML and CSS that recreates the visual design and layout of the official Ather Energy website. The project focuses on building a clean, modern, and responsive user interface, including sections like the homepage, navigation bar, product highlights, and footer. This clone was developed to strengthen front-end development skills, especially in layout design, styling, and responsive web design using pure HTML and CSS.

## Features
- Responsive Ather Energy scooter landing page clone

## Setup
Open index.html directly in browser.
